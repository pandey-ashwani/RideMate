# RideMate

RideMate is a full-stack vehicle rental platform where users can easily book scooters, bikes, and cars online. It also provides dedicated dashboards for rental owners to manage their vehicles and bookings, and an admin panel to manage the platform.

## Features

* User registration and login
* Search and book vehicles
* Vehicle management for owners
* Booking management
* Admin dashboard
* Responsive and user-friendly interface

## Tech Stack

* React + Vite
* Tailwind CSS
* Node.js
* Express.js
* MongoDB
* JWT Authentication
